# Modern SQL Data Warehouse using SQL Server

## 📌 Project Overview
This project showcases the end-to-end implementation of a modern **SQL Data Warehouse** built from scratch to consolidate sales data from fragmented business systems. It solves critical data silo and quality issues by extracting, transforming, and loading data into a unified, single source of truth optimized for analytical reporting.

The implementation follows enterprise-level engineering standards, moving raw transactional data through a structured **Medallion Architecture** to deliver actionable Business Intelligence (BI) insights.
